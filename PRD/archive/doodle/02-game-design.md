# 02 — 游戏设计

## 核心玩法循环

1. 玩家进入开始界面，点击「开始游戏」。
2. 控制涂鸦角色在画布内移动。
3. 接触星星 → 得分 +1，星星重新出现在随机位置。
4. 接触墨迹障碍 → 生命 -1；生命归零则游戏结束。
5. 结束界面展示本局分数，可一键重开。

## 操作

| 平台 | 操作 |
|------|------|
| 桌面 | `W A S D` 或方向键移动；`P` / `Esc` 暂停 |
| 触屏 | 虚拟摇杆（屏幕左下）拖动移动；暂停按钮 |

## 规则细节

- 初始生命：3。
- 画布逻辑尺寸固定（逻辑坐标），按容器等比缩放显示。
- 障碍数量随分数缓慢增加（有上限），形成难度曲线。
- 玩家与实体均为圆形碰撞（简化判定）。
- 暂停时世界停止更新，UI 仍可响应继续 / 重开。

## 界面状态

| 状态 | 内容 |
|------|------|
| `title` | 游戏名、一句说明、开始按钮 |
| `playing` | HUD：分数、生命；画布内实体 |
| `paused` | 半透明遮罩 + 继续 / 回标题 |
| `gameover` | 本局分数 + 再来一局 |

## 视觉方向

- 手绘涂鸦感：墨线角色、纸面氛围，避免纯平单色底。
- 品牌名 **Supreme Doodle** 在首屏为主要识别信号。
- 字体使用有性格的显示字体 + 可读正文（不使用系统默认无衬线堆栈作为主视觉）。
- 动效克制：开场淡入、得分轻弹、受伤闪烁即可。
