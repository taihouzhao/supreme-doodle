# 01 — 当前版本范围

来源：[00-original-brief.md](./00-original-brief.md)

## 一句话定义

一个可在手机与电脑浏览器游玩的单人历史战棋章节：十二场连续任务、固定虚构主角高大全、可批量模拟验证。

## 三条核心假设

| 编号 | 假设 | 对应验证手段 |
|------|------|--------------|
| H1 | 极简棋盘也能成立 | 真人验证：无美术条件下玩家仍愿意打完一场 |
| H2 | 决策比随机更重要 | 数学验证：三类模拟玩家呈现能力梯度 |
| H3 | 连续战役让玩家在意部队 | 真人验证：中后段主动保护高大全与高经验单位 |

真正要证明的命题：

> 玩家是否愿意为了保存一支老部队，改变当前这一关的打法。

因此第七关砥平里外线（撤退／保存主力）是章节中段的验证焦点，前六关为其积累「沉没成本」，后五关继续检验长期损耗管理。

## 范围内

- 单人网页游戏，鼠标与触屏共用「点击单位 — 点击目标」操作。
- 一个章节，十二场连续任务：突破、穿插、阻击、撤退与高地争夺交替出现。
- 跨关继承：生命、经验、疲劳、少量物资。
- 兵种 4 种、地形 6 种、道具 3 种，每种有明确且不可替代的用途；单位显示该战役的代表性武器。
- 任务简报记录日期、地点、参战编制、历史结局、地图抽象边界与史料入口。
- 晴、阴、雨、雪、雾五类天气，按战役时节限定可选范围并影响移动或射击。
- 受约束随机：敌军编成微调、援军时间窗、天气、道具与支线目标。
- 确定性规则核心 + AI Agent + 蒙特卡洛模拟器 + 平衡报告。
- 存档、设置、回放存在浏览器本地。

## 范围外

多人对战、账号体系、复杂装备树、大规模随机地图、长剧情演出、完整历史复刻、后端服务、Cloudflare R2 部署。

借用《决战朝鲜》的认知模型，不复制原作素材、文本或具体关卡。

## 当前交付物

1. 手机与电脑均可游玩的网页版本
2. 十二场连续历史任务的完整章节
3. 可批量运行关卡的模拟器
4. 平衡报告：胜率、伤亡、回合数、随机波动、战役恢复能力

## 通过之后的判据

| 结果 | 下一步 |
|------|--------|
| 公平性不成立 | 重做规则与随机模型 |
| 公平但不好玩 | 重做任务与地图 |
| 单场好玩但玩家不在意老兵 | 重做战役继承与伤亡机制 |
| 三者都成立 | 核心产品假设验证通过，进入真人试玩与部署 |
