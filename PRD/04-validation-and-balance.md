# 04 — 验证与平衡

当前版本必须同时通过数学验证与真人验证。

## 数学验证

同一关卡由三类模拟玩家在大量种子上反复运行：

| Agent | 行为 |
|-------|------|
| random | 在合法动作中随机选择 |
| basic | 朝目标推进，攻击相邻最弱敌人 |
| tactical | 考虑地形、集火、机枪架设、曲射反制、残血后撤、道具时机、兵种克制 |

### 自动门槛

实现于 `src/sim/gates.ts`，任一条不满足即视为平衡不通过。

| 门槛 | 判据 |
|------|------|
| 能力梯度存在 | random 各关胜率 < 15%；basic 落在分关难度带；tactical 各关 > 52% |
| 难度曲线存在 | 至少 7 关不能被 basic 稳定碾压 |
| 技术控制伤亡 | tactical 原则上伤亡更低；阻击关按绝对伤亡与 3.5 倍上限共同校验，避免低基数失真 |
| 策略库无全失败种子 | 每个种子至少有一种已登记策略可完成核心目标；这是搜索证据，不是数学可解性证明 |
| 随机不主导 | 同策略跨种子胜率标准差有上限；单次抖动 / 援军时间不能反转结果 |
| 无统治性策略 | 退化打法不能通吃十二关，且任一退化打法在任一单关胜率不得达到 85% |
| 无隐性死档 | 第一关重创后，第三关早期恢复检查仍有可行解；basic 十二关平均任务完成率处于 15–42%，靶心 30% |
| CI 阻断 | 类型检查、单测、构建或平衡 smoke 任一失败均阻断；平衡步骤不得 `continue-on-error` |

### 报告内容

`reports/balance.md` 至少包含：各关 × 各策略的胜率、平均伤亡、平均回合数、胜率标准差、战役续跑恢复能力，以及门槛逐条通过情况。

### 当前正式基线（2026-08-08）

- 样本：每关每策略 200 seeds；连续战役 50 seeds。
- 门槛：11/11 通过；basic 十二关平均任务胜率 40.8%，平均通关 4.90/12。
- tactical 单关最低 97.5%；random 单关最高 2.0%；退化打法单关最高 52.0%。
- 登记策略库未发现全策略均失败的种子；这不等同于数学证明所有玩家状态均可解。

## 真人验证

观察四件事：

1. 新玩家是否**不看说明**就能完成第一次移动和攻击。
2. 玩家是否能**解释失败原因**（界面需展示伤害构成）。
3. 玩家是否感受到**至少两种有效打法**。
4. 到第七关和中后段时，玩家是否**主动保护高大全与高经验单位**。

第 4 项最关键。如果玩家仍把所有单位视为可随意牺牲的棋子，即便单场战斗好玩，连续战役的核心也尚未成立。

## 失败时的处置

| 症状 | 处置 |
|------|------|
| 公平性不成立 | 重做规则与随机模型 |
| 公平但不好玩 | 重做任务与地图 |
| 单场好玩但玩家不在意老兵 | 重做战役继承与伤亡机制 |
