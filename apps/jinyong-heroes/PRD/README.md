# 金庸群侠传 · 产品需求文档（PRD）

立项定义为：

> 以 1996 年 DOS 版《金庸群侠传》为**唯一基准**，在浏览器中重新实现其全部剧情、地图、任务、人物、战斗、物品、武功、成长和正邪路线；现代化只发生在操作、分辨率、存档和兼容性层面，**不改变游戏内容与数值**。

当前仍是空项目（仅落地页）。一切实现以本文档、尤其是 [`00-original-brief.md`](./00-original-brief.md) 为准。

## 使用约定

- 需求变更先改 PRD，再改代码；`00` 为原文，不修改。
- 派生设计如与 `00` 冲突，以 `00` 为准，并在派生文档中显式记录偏差理由。
- 本仓网页引擎**不携带**原作美术、音乐、台词等受保护素材；公开发布形态见 `00` 第二节。
- 不把项目做成「类似金庸群侠传的现代武侠 RPG」。验收以旧攻略有效、状态可复现、内容全可达、不偷偷现代化数值四条硬标准为准。
