# 05 — 路线图

派生自 `00` 第十五、十六节。冲突以 `00` 为准。

## 当前承诺

**只承诺做到《连城诀》无画面闭环。** 其余阶段是方向，不是本轮交付。

## 阶段

| 阶段 | 内容 | 本轮 |
|------|------|------|
| 一 锁定原版基准 | 版本、哈希、事实库、争议录屏 | 哈希可空；事实库与版本锁文件就位 |
| 二 无画面核心 | WorldState、EventEngine、战斗、Save、ClassicRng、i16 | 做 |
| 三 《连城诀》垂直切片 | 自宅→南贤→江南山洞→北丑→天宁寺→战斗→天书 | 做最短合法路线 |
| 四 《笑傲江湖》压力测试 | 多前置、连续单挑、地牢状态 | 不做 |
| 五 其余天书与队友 | 按共用关系批量录入 | 不做 |
| 六 画面声音网页适配 | 导入器、字体、触屏、PWA | 不做；落地页说明引擎未导入原版资源 |

## 《连城诀》闭环验收

自动脚本成功且结束时：

- 拥有物品 `liancheng_book`
- Flag `heaven_book_liancheng` 为真
- 天书列表包含 `liancheng`
- 全程未使用 `Math.random()`
- 同一种子 + 同一操作序列得到同一状态哈希

## 之后加细节的流水线

1. 新事实 → `facts/`（来源 + 复现）
2. 能写成数据的进 `src/content/`，不进 UI
3. 能写成断言的进 `quest-paths` 或 `battle-golden`
4. 原版怪异逻辑进 Bug 表「必须保留」
5. 连城诀稳了再开笑傲江湖；两条都准，其余十二本主要是录入
