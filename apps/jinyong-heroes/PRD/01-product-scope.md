# 01 — 产品范围

派生自 [`00-original-brief.md`](./00-original-brief.md)。冲突以 `00` 为准。

## 立项

以 1996 年 DOS 版《金庸群侠传》为**唯一基准**，在浏览器中重新实现其全部剧情、地图、任务、人物、战斗、物品、武功、成长和正邪路线。现代化只发生在操作、分辨率、存档和兼容性层面，不改变游戏内容与数值。

原作：河洛工作室开发、智冠科技 1996 年发行的 DOS 单机战棋 RPG。核心目标是收集十四部天书、参加武林大会并最终返回现实世界。

工程名：**金庸群侠传 Web Classic Engine**。不要叫「类似金庸群侠传的网页游戏」。

## 四条硬标准

1. **旧攻略完全有效**：地图坐标、物品位置、队友加入条件、十四天书顺序与当年攻略一致。
2. **相同状态得到相同结果**：相同属性、武功、装备、位置和随机种子下，行动顺序、伤害、用毒、升级和 AI 与原作一致。
3. **全部内容可达**：十四天书、全部队友、正邪选择、秘笈装备、隐藏入口、武林大会、十大高手战均可完成。
4. **不偷偷现代化数值**：不增加装备品质、天赋树、随机词条、动态等级、任务导航、每日任务、抽卡、赛季或联网养成。

「网页游戏」只是运行方式，不是玩法改造。

## 当前交付范围（阶段三切片）

本阶段只承诺：

- 无画面核心引擎（`dispatch`、事件、战斗、存档、ClassicRng、i16）。
- 《连城诀》最短合法路线可在 Node 中自动跑通。
- 公开站点不携带原作美术、音乐、台词。

不在本阶段：其余十三本天书、完整队友网、Pixi/Phaser、增强模式 UI、原版文件导入器实现。

## 三种发布形态

本仓是公开 GitHub 并部署到 R2，**默认第二种**：

| 形态 | 本仓做法 |
|------|----------|
| 私人或内部研究版 | 不作为默认；完整复刻内容不进公开仓库 |
| 原版文件导入版 | 引擎与 schema 开源；用户本地导入自己拥有的原游戏文件 |
| 正式公开版 | 取得小说与原游戏授权后再带素材发布 |

引擎代码可以公开。原作 DAT/GRP、jynew 素材、原台词包**禁止提交**。

## 原典模式与增强模式

只维护同一套核心数据和规则。

- **原典**：原版地图/碰撞/事件范围、原版数值与 AI、不显示隐藏资质与 Flag、无任务箭头与未发现地点揭示、原版节奏、保留可玩的历史怪异逻辑、像素最近邻。
- **增强**：剧情数值战斗不变；可加快战斗速度、增加存档槽、列出**已发现**地点、查看已获知的物品/武功说明、修崩溃坏档卡死。

增强模式只能减少操作摩擦，不能降低探索和决策难度。

## 非范围（反现代化）

禁止：任务箭头、自动寻路到未发现地点、敌人等级提示、装备品质/词条、天赋树、冷却技能栏、动态等级、每日任务、抽卡、赛季、联网养成、把武功改成「主动技能+CD」。智能化战斗 AI 若存在，必须是独立挑战模式，不得覆盖原典 AI。
