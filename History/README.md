# History · 官方战史资料库

本目录存放**每一战役的官方战史与地理资料**，作为后续重做游戏地图的唯一依据。

游戏里的棋盘目前仍是战术抽象；在资料齐备后，再结合卫星地图按真实地形、道路、河流、高地与关键聚落重绘关卡。

## 使用约定

1. 每个关卡一个子目录，命名与 `src/content/missions` 中的 `id` 一致（如 `m1-onjong`）。
2. 优先收录可溯源的官方/权威战史（军事科学院战史、公开档案、当事军方战报、严肃二次文献）。
3. 每条资料写明出处、页码/链接、摘录日期；原文与摘要分开。
4. 地图相关事实单独记在 `geography.md`：坐标范围、道路、渡口、高地编号、聚落今名。
5. **未完成资料归档前，不根据印象改地图。**

## 建议工作流

1. 你把该战役官方战史检索结果写入对应目录的 `sources.md` / `timeline.md`。
2. 把地形与地标结论写入 `geography.md`（可附卫星截图、标注图，文件名自定）。
3. 资料齐后开一轮「按战史 + 卫星图重绘地图」任务，只改对应 `historical-campaign.ts` 关卡布局。

## 文件模板

每个子目录初始包含：

- `README.md` — 本战役摘要与待填清单
- `sources.md` — 资料出处与摘录
- `timeline.md` — 按日/时的作战进程
- `geography.md` — 地形、道路、地标、建议棋盘映射
