# History · 官方战史资料库

本目录存放**每一战役的官方战史、地理资料与制图约束**，作为游戏地图和任务设计的证据底稿。棋盘是战术抽象，不宣称按比例复刻整场战役；每关只选一个史料足以支撑、能在 14×10 棋盘上成立的局部切片。

## 使用约定

1. 每个关卡一个子目录，命名与 `src/content/missions` 中的 `id` 一致（如 `m1-onjong`）。
2. 优先收录可溯源的官方/权威战史（军事科学院战史、公开档案、当事军方战报、严肃二次文献）。
3. 每条资料写明出处、页码/链接、摘录日期；原文与摘要分开。
4. 地图相关事实单独记在 `geography.md`：坐标范围、道路、渡口、高地编号、聚落今名。
5. **未完成资料归档前，不根据印象改地图。**

## 证据等级

- **A（可直接制图）**：官方战史正文或官方战史地图明确给出时间、方向与地名。
- **B（可作战术抽象）**：多份权威叙述关系一致，但缺少可核到单格的坐标；只画相对方位。
- **C（仅作背景）**：单一二次资料、译名不稳定或坐标未复核；不得成为胜利条件或地图专名。

全局证据清单与逐关制图决策见 [`evidence-register.md`](evidence-register.md)；历史将领逐人登记见 [`portrait-register.md`](portrait-register.md)；人物、军衔和武器规范见 [`visual-standards.md`](visual-standards.md)；每关的 `map-reference.svg` 是关卡代码的方位底稿。

## 史实约束（重绘地图时必须遵守）

1. **温井（m1）**：师级对手是金钟五准将；局部部队为韩第6师第2团第3营及一个炮兵中队。先伏击两水洞公路，再攻温井。
2. **云山（m2）**：白善烨在 1950 年 11 月为准将；旧稿桥梁专名未获权威地图确认，统一改称“城南公路桥”。
3. **长津湖（m4）**：F/2/7 坚守 Fox Hill；玩家只在邻近主补给路形成临时路障并迟滞，不以最终夺取高地或全歼陆战第1师结算。
4. **横城（m6）**：阿尔蒙德仍为少将；主轴是横城—原州东南撤路，砥平里只作后续背景。
5. **砥平里（m7）**：守军守住城镇；玩家目标是外线压迫后北撤生存，不是攻克砥平里。
6. **铁原（m9）**：联合国军从南向北追击，志愿军弹性阻击并掩护北撤；前沿线可放弃，不做终局双点死守。
7. **上甘岭（m10）**：核心是坑道与两高地反复争夺，不是一次性占领。
8. **猪排山（m11）**：钟国楚第23军第67师参战；支撑点属于同一前哨山脊，215号T-34-85只作有限支援。
9. **金城（m12）**：本关只取第67军第199师进攻轿岩山的第一夜，开局为志愿军炮火；北汉江东翼不塞进同一棋盘。
10. **装甲（m10/m12）**：没有局部参战证据时不得配置或奖励 T-34；战役级装甲数字不得直接下放到局部地图。
