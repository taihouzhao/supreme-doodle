# 十二关字段级证据清单与制图决策

校核日期：2026-08-08。这里记录“哪一条史料支撑哪一个游戏字段”，防止把战役级态势、现代坐标推测或流行叙述直接画成精确战术地图。

## A / B / C 的实现约束

| 等级 | 证据含义 | 可进入游戏的字段 | 不得做的事 |
|---|---|---|---|
| A | 官方战史正文、官方军史地图、军方战例或可核对的人物年谱直接记载 | 人名、当时军衔、主番号、明确武器、日期、进攻方向、战果边界 | 不得把战役级配属自动下放到局部营级切片 |
| B | 多份权威叙述的相对关系一致，但无可核到单格的战术军图 | 合并后的道路、路障、支撑点、波次、阶段目标；必须标“战术抽象” | 不得声称精确坐标、精确连排阵位或唯一真实路线 |
| C | 单一二次资料、译名不稳定、未核坐标，或仅凭“全战役曾出现”外推 | 只可写入“待证/背景”，默认不生成单位、不设专名、不作奖励和胜负条件 | 不得用作人物、军衔、具体武器、关键地名、必达目标或结算条件 |

**史实硬约束**是 A 级字段以及由 A/C 边界导出的“不得误配”；代码和 UI 必须服从。**可游戏化**只限 B 级压缩，需保留战术作用与历史结果。C 级内容在取得新证据前一律暂缓。

## 设计原则

- 地图中的道路、河流、山脊只表达**相对方向与战术作用**；没有可靠军图支撑时不声明精确经纬度。
- 真实结果不是“玩家必须复刻全部战果”。任务只要求完成该切片中的合理职责，并保留失败、撤退和迟滞等不同胜利形态。
- 高大全与其直属加强营为虚构角色；真实将领只在历史资料卡中出现，不把其个人行为虚构成玩家指令。
- 天气只在史料支持的集合内随机；不能为了难度把晴天战役任意改成暴雪或暴雨。
